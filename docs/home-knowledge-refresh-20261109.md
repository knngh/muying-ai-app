# 首页介绍与知识获取优化

用户要求：首页介绍产品，知识库作为独立入口，同时优化知识内容及获取方式。

## 验收范围

- `/` 无需登录显示产品介绍、实际使用场景、阶段入口和来源说明；不请求文章 API。品牌与导航可以返回首页。
- `/knowledge` 保持免费浏览。阶段、分类、标签、关键词、原文语言和排序写入 URL；直达、刷新、后退一致。
- 推荐阅读先呈现面向家庭的实用科普，医生指南和新闻仍可检索。中文原文筛选作用于完整结果集而非当前页。
- 中文采集保留嵌套正文容器中的完整内容，避免把导航当正文；元数据不依赖属性顺序。以公开实际来源检查，新增可回归的嵌套页面样例。
- 仅在已核实可访问的中文营养栏目上增加有限采集；保持既有审核、OCR 和发布门槛。
- 来源日期与收录日期区分，详情可以直接打开原文。

## 实施顺序与验证

1. React / CSS Modules 首页、路由、导航与 Worker SEO；Playwright 验证公开首页和移动布局。
2. Zustand + React Router URL 筛选、共享 API 参数和服务端筛选；浏览器覆盖直达、后退和刷新，Jest 覆盖参数及缓存隔离。
3. 中文抽取、有限来源配置、推荐及发现排序；Jest 回归，公开页面只读抽取核验。
4. 前后端 lint、类型检查、构建及 web e2e；保存截图和验证结果。

代码沿用现有 TypeScript 风格和设计变量；不增加依赖、不修改数据库结构。前端位于 `frontend/src`，API / 采集位于 `src`，回归测试位于 `frontend/e2e` 和 `tests`。初始预览阶段不部署；用户随后报告线上点击出错，发布范围纳入网页与配套知识接口，先准备回滚再验证线上。

命令：根目录 `npm run build`、`npm run lint`、`npm test -- --runInBand <测试路径>`；frontend 内 `npm run lint`、`npm run typecheck:e2e`、`npm run test:e2e -- --workers=2`。

- 后端构建、lint 通过；使用测试占位 JWT、不可连接的本机数据库地址以及 `RUN_INTEGRATION_TESTS=false` 运行全量 Jest：117 个套件、813 项通过，需真实数据库的 2 个套件 / 26 项未运行。日志位于 `/private/tmp/muying-backend-tests-20261109.log`。
- 截图及只读链接检查：`/Users/zhugehao/muying-home-review-20261109/`。
- 本地 Worker 完整发布冒烟通过：介绍页/知识库独立 canonical、API JSON/分页、401/no-store、通知脚本、动态 llms.txt、sitemap、文章正文/结构化数据及深链接。冷启动时索引异步预热，冒烟对静态 llms.txt 回退最多等待 18 秒，超时仍判失败。

用户确认发生在 `hibeihu.com`，显示带刷新按钮的应用错误页。线上 `/version.json` 是 `6c29991a736e9d8410c7c81df5944ecd0891289a`（2026-10-28 构建）；本轮修改尚未发布。

- 新浏览器实测线上知识库、首篇详情及未登录导航正常，没有复现用户当前会话的异常堆栈；未使用或修改用户账号。
- 已核实线上缺失的脚本 URL 会返回 HTTP 200 / HTML。模拟“旧页面引用的详情模块被删除”能够复现同样的“页面出错了”。按 [Vite 官方错误处理机制](https://vite.dev/guide/build.html#load-error-handling) 监听 `vite:preloadError`，60 秒内最多自动重载一次当前目标页；持续失败保留手动刷新，避免循环。两种浏览器故障注入测试均通过。这是已验证的故障路径，尚不能据此确认用户会话的根因。
- 另在本地生产预览复现：`/api/v1/categories` 等被 SPA 回退返回 HTML，分类值成为 undefined 后 `.map` 崩溃。已加入预览 API 代理、HTML 响应拒绝和分类/标签/文章列表结构检查。异常时显示可重试提示，保留导航；故障注入与恢复测试通过。
- 未拦截 API 的本地生产预览已验证：首页 → 知识库 → 真实文章、六个主导航入口均没有控制台或页面异常。
