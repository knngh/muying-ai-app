# 知识库正文质量修复

## 问题与规则

线上最近更新列表曾把 WHO 埃博拉新闻、法语页面和只有 218 词的英文页面排在前列。旧规则的英文最低正文长度为 180 词，且中文标题或摘要会让英文正文跳过长度校验。

- 英文原文经过正文清洗后至少 300 词；标题、来源 URL、导航和推荐问题不计入正文。ACOG 短问答同样适用，原始材料保留。
- 正文语言和来源元数据共同决定长度校验；引用英文来源的中文问答保留，中文展示标题不能让英文短文通过。
- WHO 仅接收中文、英文路径；埃博拉等无关来源页面过滤，疫苗分类不能单独证明母婴相关性。新采集的 WHO 中文页面保留中文语言信息。
- 权威文章 API 默认推荐阅读，显式 `sort=latest` 仍按时间排序；网页原有排序选项继续可用。
- 修复 Zod 查询校验层自动补入 `latest`、覆盖控制器默认排序的问题；回归测试覆盖校验后到排序选择的实际链路。
- ACOG 资源目录不能作为文章或问答检索向量进入知识库；旧中文页脚继续清洗。
- 长文翻译逐段覆盖整篇，freellm 优先；全部分段完成后才写入译文。旧的前段节选缓存失效，数字与过短分段校验失败时不发布半篇译文。AI 排版只标注原文结构，不扩写凑字数。
- 对已发现的 CMV、对乙酰氨基酚、包皮环切术和伐昔洛韦误译增加原文术语表与校验；三篇有明确误译的文章通过 freellm 完整重译，并对照英文纠正 CMV 页中的药名、经胎盘感染和非整倍体术语。
- ACOG 临床 FAQ 的分享、收藏、PDF、展开折叠控件与文后推荐资源单独清理，保留医学警告和临床适用范围说明。
- 排版输入将中文问句与回答按句分开；超过 80 字符、含多句正文的模型标题降为正文。模型标为 `chrome` 的文本仍按正文输出，避免网页过滤 `aside` 时误删医学内容。
- 正文目录默认折叠，展开后可跳转章节，避免长目录把手机正文推到多屏之后。
- 实际 freellm 长篇标注曾出现 JSON 键引号缺失。现按最多 32 段分批标注，要求 JSON 输出，每批验证完整覆盖，再校验整篇拼合内容；后续分段失败时不会返回部分排版。
