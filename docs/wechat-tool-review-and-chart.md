# 微信工具回顾与体重曲线验收

日期：2026-09-21。范围：微信端界面、回顾本机生命周期与体重绘图；无新后端发布、数据库操作或微信上传。

## 使用链路

1. 工具保存原始记录后进入历史，正文和日期可再次打开。
2. 有记录时出现折叠的“记录回顾”，在记录/历史标签下均可访问，历史列表优先显示。
3. 展开后默认选中最近保存的最多 20 条，可取消、重新选择或加载更早的记录。卡片显示本次实际整理文本；单条上限 300 字，截断有省略号。
4. “生成本机摘要”完全在设备计算。云端 AI 开关开启且已登录时，用户另行勾选同意，再发送所选日期、文字及阶段；记录 ID、账号信息和图片路径不进入回顾正文。
5. 结果显示来源、条数、阶段、生成时间和免责声明。只有点击“保存这份回顾”才持久化；回顾不覆盖体重、日记等原记录。
6. 再次进入，从“已保存回顾”打开；打开时恢复该回顾的选择范围。删除回顾不会删除原记录。删除/修改来源记录后，关联回顾在下一次读取时清理。

回顾储存键为 `beihu:tool-reviews:v1:<owner>:<toolId>`，每个工具最近 10 份，账号/游客分别保存。既有原始工具记录仍为全设备储存，尚未迁移为账号隔离；不自动上传或归属给账号。

## 结果与失败边界

- `AI 生成内容`：服务端返回 AI 结构化结果，保留模型标识。
- `服务端规则摘要`：本次记录已发送，但服务端使用确定性摘要，不误称本机计算。
- `本机摘要`：直接选择本机整理，或 AI 请求失败后在设备生成。失败场景明确提示请求可能已经送达服务端。
- API 返回结构无效时回退本机摘要，避免渲染 `undefined.highlights` 等错误。
- 选择、阶段、原记录正文、来源版本或账号改变会使未保存结果失效。请求使用版本校验，页面离开或原记录变化后，迟到响应不能恢复旧结果。
- 登录过期/账号变化时丢弃响应并提示重新登录，不将该结果保存到新的账号范围。

## 曲线与界面

曲线由代码计算，与模型无关。先排除无效日期/数值，再按测量日期、同日保存时间排序，取最近 12 点。横轴使用实际日历天数；同日的多个测量共用横坐标。纵轴显示公斤刻度，用户用前后按钮查看每个原始数值。没有足够有效点时显示空状态。

Canvas 从组件容器测量宽度；宽度改变时重建画布，避免 uni-app H5 ResizeObserver 保留被旧尺寸裁切的位图。历史标签隐藏时不绘图，切回记录后重新测量绘制。组件卸载时注销窗口监听。

报告草稿的顶部计数和快捷入口与自己的历史列表一致。其他记录工具补齐已存日期的可见控件，照护时间使用所选当地日期/时间转换为 ISO 时间储存。

## 验证

- 8 个相关测试套件合计 50 项通过，其中新增 11 项覆盖真实日期间距、坏数据、同日排序、保存恢复、账号/工具隔离、来源变更清理、正文截断和结果结构校验。
- 小程序 TypeScript 类型检查、微信生产构建通过；新增测试的 ESLint 和 `git diff --check` 通过。构建仍有既有 Browserslist 数据过期及 Sass legacy API 提示。
- 使用隔离浏览器上下文和合成记录检查 320/375/430 宽度；实际检查 Canvas 像素延伸到末点、逐点查看、标签切换、保存回顾、刷新恢复、原记录删除清理、报告数量及快捷入口。15 个入口无页面脚本异常、无横向溢出。
- 使用模拟 API 验证精确勾选的发送内容、授权、AI 标識、迟到响应丢弃、服务端规则来源标识及网络失败本机回退。未调用真实模型或发送真实用户记录。
- 微信开发工具使用临时游客项目和合成数据打开 15 个入口，未捕获运行时异常。回顾选择/保存/重新进入，报告保存/数量/快捷入口/重看，以及照护、生长、辅食、日记、记账、疫苗的保存/离开/重看通过实际组件交互；未捕获异常或 error 控制台消息。

本地验证脚本与截图位于 `/private/tmp/beihu-review-ui-check/`，属于临时验收产物。微信真机、图片授权、扫码、正式账号登录及生产模型文本质量不在本次验证结论内。
