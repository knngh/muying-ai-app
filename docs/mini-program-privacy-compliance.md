# 微信小程序隐私合规处理说明

适用小程序：贝护妈妈（`wx77c66576e02a48dc`）

平台通知要求在 **2026 年 9 月 26 日前** 完善《用户隐私保护指引》。代码侧已经与实际采集链路对齐，但最终生效必须在微信公众平台后台人工保存，并重新提审代码。

## 已完成的代码处理

- `mini-program/src/manifest.json` 开启 `__usePrivacyCheck__`，并为相机配置“用于拍摄并上传孕育记录照片”的用途说明。
- 未在 `mp-weixin.requiredPrivateInfos` 中声明 `chooseImage`。该字段只适用于微信要求的指定隐私接口，照片选择应通过隐私保护指引和运行时授权处理。
- `mini-program/src/pages/calendar/index.vue` 在调用 `uni.chooseImage` 前调用 `uni.getPrivacySetting`。需要同意时显示隐私授权弹窗，使用 `open-type="agreePrivacyAuthorization"` 的按钮；拒绝后不上传照片，但仍可浏览知识库和日历。
- `mini-program/src/pages/privacy-policy/index.vue` 提供与当前代码一致的可读版指引；登录页和“我的”页均提供入口。

## 公众平台后台操作

1. 登录 `https://mp.weixin.qq.com`，选择小程序“贝护妈妈”。
2. 进入“设置 -> 服务内容声明 -> 用户隐私保护指引”。不同后台版本可能显示为“设置 -> 基本设置 -> 用户隐私保护指引”，以页面实际菜单为准。
3. 逐项填写收集信息、使用目的、处理方式、保存期限、用户权利和客服联系方式，保存并提交审核。
4. 在“开发 -> 开发管理 -> 开发版本”上传包含本次代码的微信小程序构建包，提交审核时确认隐私保护指引已关联并发布。
5. 真机重新打开小程序，进入“日历 -> 我的记录 -> 添加照片”验证：首次上传出现授权弹窗，同意后才能打开相册/相机；点击“暂不同意”仍能正常浏览知识库和日历。

## 可复制的收集与使用文案

按后台实际字段拆分填写时，可使用以下内容，并根据平台字数限制微调：

1. **微信用户标识**：用户使用微信快捷登录时取得登录凭证，服务端向微信换取 OpenID，用于识别账号、保存登录状态和孕周进度。
2. **孕育或健康相关信息**：用户主动填写孕育阶段、孕周、预产期、宝宝出生日期、性别、喂养方式、照护角色和发育关注等，用于生成孕周日历、阶段提醒和个性化内容。拒绝填写不影响公开知识库浏览。
3. **用户发布的内容**：用户主动保存的孕育日记、待办、完成状态、收藏和阅读历史，用于提供记录、回顾和提醒功能。
4. **照片信息**：用户主动选择或拍摄并上传的照片，仅用于保存孕育记录。代码在上传前请求微信隐私授权，拒绝授权不影响其他功能。
5. **日志与设备相关信息**：服务端为安全和故障排查记录请求时间、IP 地址、用户代理、接口结果和错误日志；小程序生成客户端 ID、会话 ID 和页面事件，用于服务质量分析。

不应勾选当前代码没有使用的能力，例如手机号、通讯地址、精确地理位置、定位、通讯录、微信运动、录音、身份证件等。

## 存储和第三方处理方

- 小程序生产接口默认是 `https://beihu.me/api/v1`。
- 孕育记录照片默认写入服务端 `/uploads`。当生产环境启用 `UPLOAD_STORAGE_DRIVER=cos` 或 `COS_STORAGE_ENABLED=true` 时，照片会由腾讯云对象存储 COS 保存并提供访问。
- 若后台要求填写委托处理方，仅在生产确实启用 COS 时声明“腾讯云 COS，用于孕育记录照片存储与访问”；未启用时不要虚构第三方处理方。
- 账号密码在服务端以哈希形式保存，生产接口使用 HTTPS 传输。不要在后台填写代码无法证明的“端到端加密”或固定删除时限。

## 提审前检查

```bash
npm --prefix mini-program run build:mp-weixin
```

确认构建产物 `mini-program/dist/build/mp-weixin/app.json` 包含：

```json
{
  "__usePrivacyCheck__": true
}
```

如果真机仍提示 `api scope is not declared in the privacy agreement`，先确认后台指引已经保存并发布，等待几分钟后清理开发者工具授权数据，再重新打开小程序验证。
