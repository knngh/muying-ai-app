# 知识库内容与阅读质量

目标：现有文章和新抓取内容使用同一套完整翻译、质量审查和排版流程，优先使用 freellm。

验收条件：

- 翻译使用 JSON；格式错误或内容缺失可重试，不发布半篇译文。短文章也校验数字和已知医学术语。
- 网页翻译请求与后台预热调用同一实现，默认不转到余额不足的其他供应商。
- freellm 审查文章的相关性和正文质量；审查覆盖正文首尾，失败内容不自动发布。
- 排版保留全文，合并相关句子为自然段，明确呈现标题、问答和列表；模型错误可重试。
- 现有内容批量处理使用独立缓存，合并前校验原文指纹，备份并避免覆盖后台新增记录。
- 线上移动端和桌面端验证正文完整、列表与标题清晰、无溢出或页面崩溃；记录处理数量和未完成项。

实施顺序：翻译与审查修复 → 排版修复 → 回归与构建 → 线上代码部署 → 批量审查、翻译和排版 → 浏览器验收。
