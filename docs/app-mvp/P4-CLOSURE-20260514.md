## 5. 当前非阻塞风险

以下问题不阻塞 P4 收尾，但进入 P5 后需要继续观察：

- AI overview 仍为 `attention`，原因是当前真实用户 AI 入口流量为 `0`；ops 产品入口 smoke 已完整覆盖且不会污染真实覆盖统计。
- 生产翻译 provider 仍存在既有 timeout / 429 记录；当前 worker 已有预热保护，后续应按真实缓存命中率和 failure 队列趋势观察。
- Mayo Clinic 中文源 sitemap 仍返回上游 `403`，已作为外部访问限制处理，不作为当前发布阻塞项。
- 小程序聊天 UI 当前仍关闭；小程序端已补 `clientRequestId` 协议透传，但完整聊天埋点要等功能开关打开后再验证。
- 生产目录 Git commit 仍显示旧提交，这是当前同步发布方式的已知现象，不能用服务器 git log 判断部署完整性。

## 6. P5 进入条件

P5 从“继续开发”切换为“灰度上线与真实数据观察”。

建议 P5 观察指标：

- 真实 `productEntrypointCoverage` 是否开始出现首页、周报、知识详情、最近 AI、原生聊天入口流量
- `serverAi.realEntrySourceEventCount` 是否大于 `0`
- AI 请求完成率、错误率、平均延迟和 degraded rate
- 客户端 `app_chat_message_send` 与服务端 `ai_request_started` 的 `clientRequestId` 是否可对齐
- 免费用户 AI fallback 是否保持单次扣减
- 翻译缓存命中率、failure entries、blocked failures 是否持续下降或至少不扩大
