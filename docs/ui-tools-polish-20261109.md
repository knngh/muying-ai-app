# 工具入口与网页布局优化

目标：沿用贝护米白、暖橙、绿色的视觉，让用户更快打开常用工具，并让知识列表更早出现在首屏。

## 范围与验收

1. 小程序工具目录：直接打开首页常用工具；保留排序与增删；增加阶段推荐筛选、分组数量和用途说明。搜索与分类共同生效，空结果可一次恢复全部。
2. 小程序工具详情：返回和添加首页并排，缩短介绍区；记录、历史、保存提示和医疗边界保持可见。
3. 网页：缩短公共导航，增加键盘跳到正文和当前页标识；知识库在桌面使用左侧筛选、右侧列表，手机使用紧凑纵向布局；工具箱增加清晰的用途层级与日历入口。
4. 在 320、375、768、1024、1440px 检查横向溢出、首屏和导航；验证搜索、阶段筛选、常用工具、排序保存及现有关键业务回归。

## 实现约定

React 18 / CSS Modules 与 uni-app / Vue 3 使用原有模式，如 `computed(() => …)`、`className={styles.page}`；只对页面展示与本机目录筛选做小步调整。复用已有目录、阶段数据和存储函数，不增加依赖或 API，不改变用户记录的保存方式。

文件：`mini-program/src/pages/tools/index.vue`、`pages/tool-detail/index.vue`；`frontend/src/components/Layout/`、`pages/Tools/`、`pages/Knowledge/`。先验证小程序，再验证网页与公共布局。

## 完成结果

- 小程序目录显示常用工具直达、实时分类数量、阶段推荐筛选和用途说明。搜索与阶段筛选共同生效，空结果可恢复全部；添加、排序、重载后保留顺序均已验证。默认五项常用工具采用一行展示，最多八项自动换行。
- 详情页将返回和添加首页置于同一行，压缩介绍区；记录与历史切换增加选中语义，保存位置说明提高对比度。
- 网页公共导航去掉英文副标题、大阴影与装饰渐变，增加正文跳转与当前路由语义。工具箱改用原生链接语义、用途图标与明确动作，支持打开新标签页，补充日历入口。
- 知识库在 768px 起使用左右布局；手机端分类与阶段并排，热门标签横向滚动，12 个标签不会向下撑高列表。

相同两篇合成文章、两个标签，视口高 960px 的浏览器测量：

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 375px 网页导航高度 | 153.5px | 105px |
| 375px 首篇文章顶部 | 1075.8px | 607.3px |
| 1440px 首篇文章顶部 | 812.7px | 395.2px |

这衡量布局位置，不代表请求速度。另用 12 个合成热门标签回归，320/375/768/1024/1440px 均无横向溢出，首篇文章顶部低于 700px。Tab 可进入「跳到正文」，激活后焦点落在正文；工具子页维持导航选中。
