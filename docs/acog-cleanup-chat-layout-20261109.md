# ACOG 正文清洗与 AI 问答阅读布局

用户指出知识库混入 ACOG 宣传、导航和推荐问题，同时 AI 问答等页面排版混乱。

## 正文清洗

- ACOG 适配器使用现有平衡 HTML 容器提取器，保留嵌套正文，移除完整分享工具栏、About Ask ACOG 宣传块及 What to Read Next 推荐区域。规则覆盖历史中文译文的对应标识，不按通用问句或 ACOG 引用删内容。
- 控制器、翻译输入与旧翻译读取统一清洗；不因正文短于旧的 150 字符阈值而保留导航。新采集仍经过原有发布质量门槛。
- `src/scripts/clean-acog-content.ts` 默认只生成计划。写回必须设置 `WRITE_BACK=true` 和绝对路径 `ACOG_CLEAN_BACKUP_DIR`，暂停 API/采集/排版写入进程后执行。先备份受影响缓存与数据库正文，再清洗规范化数据库、原文和中文缓存，并删除受影响的旧排版缓存。原始 HTML、来源日期和原文哈希不改动，不绕过译文新鲜度校验；当前生产受影响译文的来源日期与记录一致。
- 检索向量单独备份原文与 embedding，再对已有受影响条目更新正文及 embedding，按原 ID upsert，检查写入数量及强一致读取结果。未执行整库重建。

## 问答阅读

- 替换依赖全局 prose 的排版，明确段落间距、标题层级、列表、引用、表格和代码样式。表格/代码仅在自身区域横向滚动；长 URL 和参考来源换行，卡片允许收缩。375px 回答卡片从约 255px 增至 317px，段落底部间距从 0 增至 16px。
- 正文中的建议保持原样；仅忽略 Markdown 符号和空白后检查重复文字，补充展示正文中未出现的结构化结论、全部行动建议、原因和就医提示。删除原来只展示前三条行动建议的截断。
- 参考来源改为有序列表和标准外部链接，限制为 HTTP(S)，加 noopener/noreferrer。用户问题按普通文本保留换行。
- 页面最大宽度 1040px，回答正文最大 760px；历史标题限制两行，减少说明区首屏占用，输入框增加可访问名称。就医提示始终可见，完整说明可展开。

## 验证

- 旧提交的 ACOG 控制器回归测试准确失败，当前通过：清理原文/中文/推荐问题，保持医学数字和警告，旧全文对应的 AI 排版失效，详情不调用模型。
- 旧前端在同一浏览器回归中无法显示第四条结构化建议；新前端 320/375/768/1440px 检查通过，覆盖段落间距、长表格、来源链接、独有就医提示及页面溢出。
- 后端构建、lint、124 个套件 / 848 项测试通过；26 项依赖真实数据库的集成测试未运行。网页构建、lint、类型检查与 43 项 Playwright 测试通过。
- 浏览器截图中的问答内容为接口模拟数据，用于验证渲染，不代表对实际医学模型回答质量的验收。

生产发布、清洗数量与回滚位置在上线后补充。

清洗后的线上检查额外发现：ACOG 官方短问答原来依赖导航字数通过 180 英文词门槛；清理后被误判成不完整文章。为 ACOG 真实域名及 Ask ACOG 单篇路径增加有限例外，仍要求至少 40 词和两句完整正文，其他来源/路径/不完整内容继续使用原门槛。相关回归先失败再通过。
