# 微信日记自然周（2026-09-23）

入口：工具目录搜索“周记” → 孕育日记。日期条按周一至周日展示自然周，点击某日筛选，支持上一周、下一周、日期定位与回到本周。原日历仍按孕周承载既有周记，不把旧周记拆成七天。

## 内容与统计

日记日期是用户选定的日历日期；周边界计算使用 UTC 日历运算以免夏令时偏移，不把日期解释为上传时间。同日可多篇，记录天数去重，篇数及心情标签按原记录计数。心情可以留空，不依据文字猜测；早期默认选择的心情按已有标签展示，不声称全部由用户主动勾选。

列表展示前 120 字，省略有标记；历史可看完整原文和多行文本。新文字最多 800 字，保存读取 form submit 的实时内容。无有效日期/正文或非每日类型的旧记录显示在未归组区，保留来源。原日历周记从工具底部日历入口查看。

周摘要是随原记录计算的视图，无单独副本。修改、改期或删除会重算；账号变化重置输入、筛选和展开状态。本机记录仍受最近 500 条总上限约束，不能当作全量云档案。

## “整理这一周”的契约

DiaryJournal 发出 weekStart；页面重新读取当前账号记录，按该周筛选并调用已有回顾组件的 prepareSelection(ids)。这一步仅预选并展开，无模型请求和自动授权。最多选择 20 篇，超过时按日期选前 20 篇并提示，可取消和替换。回顾正文仍按既有规则每篇最多 300 字，有省略提示。

已保存回顾校验使用全部原记录，切换周不会删除其他周的回顾；原文修改/删除才清理。预选后来源变化会清空选择及授权，请用户回到周记重选。生成或保存前校验当前账号；请求中删除来源或切换账号，旧结果不能恢复。

这里接入既有 Jev/GLM 回顾通道，未新增模型能力；没有实现跨工具周记、自动润色、日记图片或语音。

## 验证与复现

- diary-week.test.ts：6 项，含跨年、闰日、夏令时日期、同日多篇、缺心情、全文保留、未归组、改期删除、输入校验与 20 篇限制；相关回归合计 7 组 36 项通过。
- check-diary-ui.cjs：隔离浏览器合成数据，快速编辑保存、补记、周/日筛选、全文/删除、保存回顾重进、跨周不误删、原文变化重选、旧记录/分页、账号隔离和存储失败；320/375/430 宽度。
- check-diary-ai-ui.cjs：另启 AI 开关的本地 H5 实例；远端全部用响应桩，检查主动授权、单周请求正文、来源标识、结果保存、延迟返回期间删原文的结果丢弃。未调用生产模型，不能算供应商可用性测试。

复现需已安装 Chrome 与 Playwright（可在独立目录安装，通过 NODE_PATH 指向 node_modules）：

    npm --prefix mini-program run dev:h5 -- --host 127.0.0.1 --port 5198
    NODE_PATH=/path/to/ui-test/node_modules node mini-program/scripts/check-diary-ui.cjs

模拟 AI 流程使用另一个本地服务：

    VITE_TOOL_AI_ENABLED=true npm --prefix mini-program run dev:h5 -- --host 127.0.0.1 --port 5199
    NODE_PATH=/path/to/ui-test/node_modules node mini-program/scripts/check-diary-ai-ui.cjs

普通流程截图默认存系统临时目录 beihu-diary-ui，可用 BEIHU_UI_OUTPUT_DIR 覆盖。浏览器日期选择使用 change 事件，只验证业务链路；微信原生日期选择、键盘、后台重进与真实存储仍需开发者工具/真机检查。CLI 服务端口未开启，本批未上传微信版本。
