## 发布范围

| 接口 | 行为 | 当前状态 |
| --- | --- | --- |
| `GET /api/v1/names` | 静态候选库筛选，响应包含 AI 辅助整理及待复核说明 | 200，32 条预览样本；默认筛选双字名 |
| `POST /api/v1/names/evaluate` | Jev 对库内候选按所选风格做闭集评测，低置信度不评分 | 登录后因开关关闭返回 503 |
| `POST /api/v1/tool-records/ai-review` | 整理用户主动提交的文字记录；Jev 先选整理重点，官方 GLM-5.3 负责中文表述 | 登录后因开关关闭返回 503 |

记录回顾支持宫缩、胎动、体重、照护、生长、待产包、疫苗、辅食、日记、记账十类工具。不接收报告图片、相册图片或客户端指定模型。

两个 POST 接口使用既有认证、限流和配额。严格请求校验之后、配额和供应商调用之前检查开关；关闭时不扣额度、不调用模型，响应 `Cache-Control: no-store`。接口不保存记录原文和模型结果到服务器数据库。

## 模型与降级

- 起名：`jev-1.13.0`，仅对当前库内 1–5 个候选、1–3 个固定风格进行评测；不生成新名字、出处或寓意。评分解释与计算由代码完成。
- 工具回顾：先调用 Jev 选择固定整理重点，再用智谱官方 `glm-5.3` 输出中文 JSON。新增独立配置 `TOOL_REVIEW_GLM_API_KEY`，不复用或改动线上知识库的 `AI_GLM_*` 绑定。
- 各供应商请求超时 12 秒，无自动重试；最坏累计模型等待约 24 秒，客户端预算 30 秒。
- JSON 结构不合格、内容含已拦截的医疗判断用语、供应商失败时，返回明确标为 `rules` 的固定摘要。不会把整个回退结果标成 AI 文案。
- 当前内容检查包含结构约束、提示词边界和关键词拦截，并不代表已完成医学语义安全或中文整理质量评测；开放前仍须做样本验收。
